# Shohnoma.uz — loyiha qoidalari

- Next.js 15 statik eksport + PHP 8.2 API (`php/api`), MariaDB. Deploy: `main` → GitHub Actions → `deploy` branch → Plesk «Получить сейчас».
- Foydalanuvchi bilan **o‘zbekcha** gaplash; qisqa, aniq; tekshirilmagan narsani ochiq ayt.
- **Taklifnoma shabloni yasash yoki tuzatishdan oldin `docs/SHABLON-QOIDALAR.md` ni to‘liq o‘qi va unga qat’iy amal qil.** U mijozning barcha oldingi talablaridan yig‘ilgan; ularni qayta aytishga majbur qilma.
- Motion yo‘riqnomasi: `docs/SHABLON-MOTION.md` (Figma asosiy manba).
- Bitta xato aytilsa — shunga o‘xshash xatolarni butun saytda tuzat.
- Maxfiy kalitlar faqat server `.env` yoki Admin → Sozlamalar’da; hech qachon commit qilinmaydi yoki chatda so‘ralmaydi.
